## 📖 О проекте
Это тестовое веб-приложение на Django, полностью упакованное в Docker. 
Проект демонстрирует навыки DevOps: контейнеризацию, работу со статикой и автоматическую проверку кода (CI/CD).

### 🚀 Технологический стек
* **Python 3.11** — язык программирования.
* **Django 5.0** — веб-фреймворк.
* **Docker & Docker Compose** — контейнеризация и оркестрация.
* **Gunicorn & WhiteNoise** — сервер приложений и раздача статики.
* **GitHub Actions** — автоматическая проверка сборки (CI).

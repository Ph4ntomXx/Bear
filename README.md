# 🐻 Bear Django Project

Это тестовое приложение на **Django 5.0**, упакованное в **Docker**. В проекте настроена красивая админка (Jazzmin) и система трекинга посетителей.

## 🚀 Как запустить проект

Тебе не нужно устанавливать Python или зависимости на компьютер. Достаточно, чтобы был установлен **Docker**.

### 1. Сборка образа
Открой терминал в корне проекта и выполни:

```bash
docker build -t my-django-site .
```
